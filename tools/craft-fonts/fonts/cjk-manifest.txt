# Fork-only Simplified Chinese faces, embedded on **every** target including wasm32.
# Same 8-field format as fonts/manifest.txt:
#   family | style | file (relative to the repo root) | scripts (ISO 15924, comma-separated) | licence | licence file | sha256 | source
#
# Upstream keeps Chinese native-only, so the web build ships no Han face and every Chinese
# character is drawn as .notdef. These two faces fix that at a bounded size cost.
#
# Source: Noto Sans CJK SC Regular/Bold, commit f8d157532fbfaeda587e826d4cd5b21a49186f7c
# (the same pin fonts/manifest.txt uses), subset with fontTools pyftsubset to the GBK set
# (21,003 ideographs — everything a Chinese IME can type, so personal-name characters such as
# 龘/珺/玥 are included) plus Latin-1, General Punctuation, arrows, circled numbers, geometric
# shapes, CJK punctuation and full-width forms — 24,671 code points, 8.9 MB per weight.
# Renamed to "DeckCraft Han Sans" because this is a Modified Version under OFL-1.1 and because
# the fork's asset policy excludes the Noto CJK name; the outlines, metrics and kerning are
# Noto's. Rebuild with tools/deckcraft/tools/build-han-subset.py.
